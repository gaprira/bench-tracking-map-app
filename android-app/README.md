# 📱 Скамейки — Android-приложение

Нативная обёртка над сайтом **https://benchhunt.vercel.app** на [Capacitor](https://capacitorjs.com).
Приложение открывает сайт внутри себя, поэтому **всё, что деплоится на Vercel,
сразу появляется и в приложении** — пересобирать APK нужно только при смене
иконки, названия, разрешений и т.п.

Что работает: карта, кнопка 📍 (геолокация — Android спросит разрешение),
фото с камеры или из галереи, режим админа, кнопка «Назад».
Без интернета показывается экран «Нет подключения» с кнопкой «Повторить».

## Готовый APK

`dist/benchhunt.apk` — его можно скинуть в Telegram/на почту и установить на телефон
(Android 7+). При установке телефон попросит разрешить «установку из неизвестных
источников» — это нормально для APK не из Google Play.

## Как пересобрать

Двойной клик по **`build-apk.bat`** → через пару минут появится `dist/benchhunt.apk`.

Нужно: Node.js, JDK 21 (`winget install Microsoft.OpenJDK.21`) и Android SDK
в `%LOCALAPPDATA%\Android\Sdk` (путь задан в `android/local.properties`).

При выпуске новой версии увеличь `versionCode` (и `versionName`) в
`android/app/build.gradle` — иначе телефон не даст обновиться поверх старой.

## 🔑 Ключ подписи — НЕ ПОТЕРЯЙ

- `android/benchhunt-release.keystore` — ключ
- `android/keystore.properties` — пароль к нему

Оба файла **не попадают в git** (это секрет). Сохрани их копию в надёжное место
(облако, флешка). Если ключ потерять, новые версии нельзя будет установить
поверх старой — придётся удалять приложение и ставить заново.

## Что где лежит

| Путь | Что это |
|------|---------|
| `capacitor.config.json` | Адрес сайта, название, цвет сплэша |
| `www/offline.html` | Экран «нет интернета» |
| `assets/` | Исходники иконки и сплэша (`npx capacitor-assets generate --android`) |
| `android/` | Android-проект (можно открыть в Android Studio) |
| `android/app/src/main/AndroidManifest.xml` | Разрешения: интернет, геолокация, камера |
