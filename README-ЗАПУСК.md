# 🪑 Скамейки — карта скамеек с рецензиями

## Что это

Полноценный сайт с картой скамеек: можно отмечать скамейки на карте, добавлять фото,
ставить оценки звёздами и писать рецензии. Всё хранится в настоящей базе данных
PostgreSQL в облаке — данные не пропадают.

## 🌐 Постоянная ссылка — работает ВСЕГДА

**https://benchhunt.vercel.app**

- Сайт живёт на Vercel: работает даже при **выключенном компьютере**
- Ссылка **не меняется** — просто отправь её другу 📤
- Данные хранятся в облачной базе **Neon PostgreSQL**, фото — в той же базе
- Запасной адрес: https://benchhunt-gaprira121213.vercel.app

## 📱 Android-приложение

В папке `android-app/` — приложение для Android (обёртка над сайтом).
Готовый APK: `android-app/dist/benchhunt.apk`, пересборка — `android-app/build-apk.bat`.
Подробности — в `android-app/README.md`.

## 🔑 Режим администратора (модерация)

Обычные посетители могут смотреть, добавлять скамейки и писать рецензии.
**Удалять и редактировать** контент может только администратор.

Как войти:
1. На сайте нажми кнопку **🛡** в шапке (справа, рядом с 📍)
2. Введи ключ администратора: **`skameyki-admin-7k2m9q`**
3. Кнопка станет зелёной «🛡 Админ» — ключ запомнится в этом браузере

Ключ задаётся переменной `ADMIN_KEY`:
- в облаке — в настройках проекта на Vercel (Settings → Environment Variables)
- локально — в файле `.env`
Не передавай ключ другу!

## 🚀 Как обновить сайт на Vercel

Сайт подключён к репозиторию `github.com/gaprira/bench-tracking-map-app`
и деплоится из его актуального кода. Проще всего — попросить ассистента
«задеплоить обновление на Vercel». Вручную из папки проекта:

```bat
npx vercel deploy --prod
```

Окружение (база, ключ админа) уже настроено в переменных Vercel.

## 💻 Локальный режим (необязательно)

Локальная копия сайта запускается как раньше: двойной клик по **`start-site.bat`**
(поднимет локальную базу PostgreSQL и сервер на http://localhost:3000).
Остановка — **`stop-site.bat`**.

⚠️ Локальная база и облачная база — **разные**: скамейки, добавленные на
benchhunt.vercel.app, не появятся на локальной копии, и наоборот.
Локальный режим теперь нужен только для офлайн-экспериментов.

## Что где лежит

| Путь | Что это |
|------|---------|
| `src/` | Код приложения (Next.js 16 + React 19 + Leaflet) |
| `scripts/migrate-to-hosted.mjs` | Перенос скамеек и рецензий из локальной базы в облачную |
| `scripts/import-uploads.mjs` | Импорт фото из `public/uploads` в базу (в облако или локально) |
| `pgsql/` | Портативная база PostgreSQL 17.6 для локального режима |
| `pgsql/data/` | Данные ЛОКАЛЬНОЙ базы (старые записи до переезда в облако) |
| `public/uploads/` | Старые фото-файлы (уже перенесены в базу, оставлены как резерв) |
| `tools/cloudflared.exe` | Туннель Cloudflare (больше не нужен) |
| `.vercelignore` | Что не загружать при деплое на Vercel |

## Возможные проблемы

- **Друг не может открыть сайт** — проверь https://benchhunt.vercel.app сам;
  если «Сайт не отвечает», зайди в панель vercel.com → проект benchhunt →
  Deployments: статус последнего деплоя должен быть Ready.
- **Хочу свой домен** (например, skameyki.ru) — купи домен у любого регистратора
  и попроси ассистента подключить его: Vercel сам выпустит HTTPS-сертификат.
- **Облачная база заполнена** (лимит бесплатного Neon ~512 МБ) — фото сжимаются
  при загрузке (~100–300 КБ), этого хватает на тысячи скамеек. Если всё же
  заполнилась — удали старые фото скамеек в режиме админа.
