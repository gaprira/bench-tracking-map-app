# 🪑 Скамейки — как запустить сайт и скинуть другу

## Что это

Полноценный сайт с картой скамеек: можно отмечать скамейки на карте, добавлять фото,
ставить оценки звёздами и писать рецензии. Всё хранится в настоящей базе данных
PostgreSQL на твоём компьютере — данные не пропадают.

## Быстрый запуск (каждый раз)

1. Двойной клик по **`start-site.bat`** (в папке `D:\bench-tracking-map-app`)
2. Подожди: скрипт поднимет базу, сервер и туннель (обычно ~15 секунд)
3. Откроются два окна:
   - **«Bench site - SERVER»** — сам сайт (можно закрыть только при остановке)
   - **«Bench site - TUNNEL: your public LINK here»** — в нём строка вида
     `https://xxxxx.trycloudflare.com` — **это и есть ссылка для друга!**
4. Скопируй ссылку из окна туннеля и отправь другу 📤

## Остановка

Двойной клик по **`stop-site.bat`** — остановит всё. Данные сохранятся в базе.

## 🔑 Режим администратора (модерация)

Обычные посетители могут только смотреть, добавлять скамейки и писать рецензии.
**Удалять и редактировать** контент может только администратор.

Как войти:
1. На сайте нажми кнопку **🛡** в шапке (справа, рядом с 📍)
2. Введи ключ администратора: **`skameyki-admin-7k2m9q`**
3. Кнопка станет зелёной «🛡 Админ» — ключ запомнится в этом браузере

Что может админ:
- **✏️ Изменить** — исправить название/описание любой скамейки
- **🗑 Удалить** — удалить скамейку (кнопка видна только админу)
- **✕ у рецензии** — удалить конкретную рецензию (двухшаговое подтверждение)

Как сменить ключ: открой файл `.env`, поменяй значение `ADMIN_KEY=` и
перезапусти сайт (`stop-site.bat` → `start-site.bat`). Не передавай ключ другу!

## Важно знать

- **Сайт работает, пока включён твой компьютер.** Выключил ПК или закрыл окна —
  ссылка перестала открываться. Это нормально: друг просто зайдёт позже, когда
  ты снова запустишь `start-site.bat`.
- **Ссылка меняется при каждом запуске** — это ограничение бесплатного Quick
  Tunnel без регистрации. После перезапуска скопируй из окна туннеля новую
  ссылку и скини её другу ещё раз.
- Первая загрузка сайта у друга может занять пару секунд (карта подтягивает
  OpenStreetMap).
- Если друг «в той же Wi-Fi сети», можно вместо туннеля дать ему адрес
  `http://10.6.7.1:3000` (твой IP в локальной сети) — работает быстрее.

## Что где лежит

| Путь | Что это |
|------|---------|
| `start-site.bat` | Запуск всего сайта одной кнопкой |
| `stop-site.bat` | Остановка всего |
| `pgsql\` | Портативная база данных PostgreSQL 17.6 (не трогать) |
| `pgsql\data\` | **Все твои данные** — скамейки, рецензии. Не удалять! |
| `public\uploads\` | Загруженные фото скамеек |
| `tools\cloudflared.exe` | Программа туннеля Cloudflare |
| `src\` | Код приложения (Next.js 16 + React 19 + Leaflet) |

## Возможные проблемы

- **«PostgreSQL failed to start»** — посмотри файл `pgsql\server.log`.
  Обычно помогает перезапуск `start-site.bat` (если база уже запущена,
  скрипт это поймёт и не будет запускать второй раз).
- **Друг не может открыть ссылку** — проверь, что запущен `start-site.bat`
  и окно туннеля открыто. Обнови ссылку — при перезапуске она новая.
- **Хочу постоянную ссылку, которая не меняется** — скажи ассистенту,
  подскажем вариант с бесплатным аккаунтом Cloudflare + своим доменом
  или переездом на Vercel (тогда сайт работает даже при выключенном ПК).
